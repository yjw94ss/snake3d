# 3D 贪吃蛇 · 小小探险

一个给孩子玩的 3D 贪吃蛇小游戏。彩虹色的小蛇在草地上吃水果，每吃一口就长一截。

**在线试玩**：https://yjw94ss.github.io/snake3d/

单文件 HTML，three.js 已内联，**不联网、不装环境、双击即可玩**。

---

## 玩法

| 操作 | 说明 |
|---|---|
| 方向键 / `W` `A` `S` `D` | 控制转向 |
| 手指滑动屏幕 | 手机端转向 |
| 屏幕右下方向键 | 触屏虚拟按键 |
| 空格 / `Esc` / `P` | 暂停 |

- 吃水果 +10 分，身体长一节，颜色沿身体渐变彩虹
- 撞到围栏或咬到自己则结束
- 每吃 4 个水果自动提速一点点，最快速度有上限
- 最高分自动保存在本机浏览器

三档难度：**慢慢爬**（4 岁+/每秒 3.3 格）、**刚刚好**（每秒 4.2 格）、**再快些**（每秒 5.6 格）。

---

## 特点

- **真 3D**：46° 斜俯视，有实体围栏、草地、树木、蝴蝶、实时阴影
- **相机自适应**：用二分法把场地四角投影到屏幕，反解出刚好装下整个场地的相机距离，横屏竖屏都不切边
- **竖屏专门适配**：卡片压缩贴底、取景中心前推，让场地露在上方；触屏自动出现大号方向键
- **性能克制**：蛇身用单个 `InstancedMesh`（主球 + 中点补缝球），长到 40 节时 draw call 仍是 37 个，约 4 万三角形
- **零外部资源**：棋盘格、草地、天空渐变、小花全部程序化生成；音效与背景音乐由 WebAudio 实时合成，没有音频文件

## 本地运行

直接双击 `index.html` 即可（`file://` 协议已验证可用）。

想用本地服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 修改后重新打包

源码在 `src/`，用 `build.py` 拼成单文件：

```bash
python3 build.py      # 重新生成 index.html
```

`assets/three.min.js` 是 three.js r158 的 UMD 构建（r160 之后官方移除了 UMD，所以锁在 0.158.0）。

## 目录

```
index.html          打包好的成品（线上就是这个文件）
build.py            拼装脚本 + 自检（标签配对 / 无外链 / JS 语法）
src/template.html   HTML 骨架
src/style.css       UI 样式
src/game.js         全部游戏逻辑
assets/three.min.js three.js r158
```

## 技术栈

原生 JavaScript + three.js r158 + WebAudio API，无框架、无构建工具链、无 CDN 依赖。
